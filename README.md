# АудіоСкан

Фронтенд вебзастосунку для аналізу аудіозаписів і виявлення дефектів звуку (кліпінг, провали сигналу, клацання, фоновий шум, гул мережі 50 Гц, DC-зміщення).

Індивідуальний STEM-проєкт з ОК «Розробник фронтенду програмних систем».

## Технології

- React 19 + TypeScript
- Vite (дев-сервер і збирання)
- React Router (маршрутизація)
- wavesurfer.js (хвильова форма та відтворення)
- Web Audio API (декодування аудіо, розрахунок рівнів сигналу)
- CSS (власні стилі, адаптивна верстка, світла й темна теми)

## Запуск

```bash
npm install
npm run dev
```

Застосунок відкриється за адресою http://localhost:5173.

## Production-збірка

```bash
npm run build
npm run preview
```

Збірка доступна за адресою http://localhost:4173. Саме її варто перевіряти в Lighthouse.

## Структура

```
src/
  components/   компоненти інтерфейсу (layout, upload, result, history, ui)
  context/      контексти та провайдери (історія, налаштування, сповіщення)
  hooks/        власні хуки (useAnalysis, useHistory, useSettings, ...)
  pages/        сторінки застосунку
  services/     логіка без UI (валідація файлу, аналіз, експорт, сховище)
  constants/    довідники дефектів і налаштування застосунку
  utils/        допоміжні функції
  styles/       глобальні стилі та змінні тем
```

## Примітка

Аналіз дефектів імітується на клієнті.
